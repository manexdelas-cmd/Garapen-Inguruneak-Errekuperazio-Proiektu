# Garapen-Inguruneak-Errekuperazio-Proiektu

Java laguntza teknikorako txartelen kudeatzailea (pilak, ilarak, zerrendak eta liburutegirik gabeko ordenazioa).

## Deskribapena
Laguntza teknikoko txartelak (tickets) kudeatzeko aplikazioa. Txartelak erregistratu,
sarrera-ordenaren arabera atenditu eta ekintzak desegin ahal izango dira.

## Egitura
- **Ilara (Queue):** zain dauden txartelak (FIFO)
- **Pila (Stack):** ekintzen historia, desegiteko
- **Zerrenda estatikoa:** teknikariak
- **Zerrenda dinamikoa:** txartel guztien erregistroa
- **Ordenatze-algoritmoak:** 3 algoritmo desberdin
- **Hamartarra ↔ bitarra:** txartelaren IDaren bihurketa

## Teknologiak
- Java
- Eclipse IDE
